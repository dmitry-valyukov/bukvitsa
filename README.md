# Буквица / Bukvitsa

Зонтичный проект «домашней» экосистемы чтения, сделанной с любовью к книгам
и типографике. Windows 10/11, C++ / WinRT.

## Состав

| Модуль | Что это |
|---|---|
| **FB3/** | Библиотека формата FictionBook 3: OPC-контейнер, парсер `body.xml`/`description.xml`, модель документа, конвертер FB2→FB3, валидация. |
| **Typography/** | Библиотека вёрстки: строки и переносы (hyphenation), выключка (justification), пагинация, позиции чтения. DirectWrite. |
| **Reader/** | Приложение-читалка на `wxl.winui` (WinUI 3): витрина книг, страница, оглавление, поиск, закладки, настройки вида. |
| **external/** | Сторонние зависимости (переносы и словари; XML и OPC берутся у wxl и у Windows). |
| **docs/** | Исследования и проектные решения. |

Слои: `FB3 → Typography → Reader` (нижние не знают о верхних).

Правила проекта, состояние работ и что делать дальше — в `CLAUDE.md`;
принятые решения с обоснованиями — в `docs/decisions.md`.

## Сборка

Нужна соседняя библиотека [wxl](../wxl) — путь задаётся `BUKVITSA_WXL_ROOT`
(по умолчанию `../wxl`) — и Visual Studio с тулчейном, умеющим `import std;`.

```
tools\build.ps1                 # настроить (если нужно) и собрать Debug
tools\build.ps1 -Config Release
ctest --preset x64-debug
```

Скрипт сам поднимает окружение Visual Studio, так что годится обычная оболочка.
Генератор — Ninja Multi-Config: генераторы Visual Studio не собирают
`import std;`.

## Читалка

```
build\x64\Reader\Debug\Reader.exe
```

Книга добавляется кнопкой на заставке или перетаскиванием файла в окно;
добавленная попадает в библиотеку и открывается оттуда там же, где закрылась.

Листание — `PageUp`/`PageDown`, стрелки, пробел, колесо мыши или щелчок по
левой и правой трети полосы; `Home` и `End` — в начало и конец. Кегль —
`Ctrl` с `+`, `−`, `0` или с колесом, тема — `T`. Колонок столько, сколько
велит длина строки в знаках, а ширину их задают поля.

Ящик читалки — правой кнопкой по странице, или клавишей: `Ctrl+T` —
оглавление, `Ctrl+F` — поиск, `Ctrl+B` — закладки, `F2` — вид (тема, кегль,
интерлиньяж, поля), `Ctrl+L` — библиотека. `F11` — во весь экран. `Esc`
закрывает то, что открыто поверх страницы, потом полный экран, потом уходит
с экрана.

Сноска открывается щелчком по своему знаку и всплывает прямо под ним;
длинная прокручивается колесом и клавишами. Закрывается по `Esc` или щелчком
мимо неё.

## Тестовые данные

`FB3/testdata/` содержит три официальных примера из репозитория спецификации
[gribuser/FB3](https://github.com/gribuser/FB3) (включая стресс-тесты
`nightmare_example` и `hardcore_file_structure`) и XSD-схемы формата.
Схемы распространяются по лицензии ЛитРес (см. `testdata/schemas/LICENSE_LitRes_schemas.txt`):
использование и распространение — без изменений.
