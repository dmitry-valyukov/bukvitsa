# docs

Эти статьи — половина сайта документации (`tools\build.ps1 -Target docs`),
вторая половина — справочник из doc-комментариев; `CMakeLists.txt` рядом
собирает и то, и другое.

- [decisions.md](decisions.md) — принятые решения с обоснованиями. Начинать
  отсюда.
- [reader.md](reader.md) — то же для читалки `Reader` на `wxl.winui`: почему
  интерфейс переезжает с рукописного `Ui` на проекцию WinUI 3 и что из этого
  следует. `decisions.md` объясняет то, что было решено ещё для `Abajour`
  (удалённой первой версии), эта статья — только новое.
- [research_fb3_and_rendering.md](research_fb3_and_rendering.md) — исследование
  формата FB3, существующих реализаций и рендеринга текста под Windows
  (22.08.2026): контейнер, словарь элементов, DirectWrite, переносы,
  пагинация, архитектуры читалок.
- [typography_engines_survey.md](typography_engines_survey.md) — обзор готовых
  движков вёрстки и почему выбран свой.
- [fb3_model.md](fb3_model.md) — устройство модели книги: слои, контейнер,
  дерево узлов, позиции чтения.
