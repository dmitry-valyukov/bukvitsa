# docs

Эти статьи — половина сайта документации (`tools\build.ps1 -Target docs`),
вторая половина — справочник из doc-комментариев; `CMakeLists.txt` рядом
собирает и то, и другое.

- [decisions.md](decisions.md) — принятые решения с причинами: формат, свой
  движок вёрстки, модель книги, сборка. Начинать отсюда.
- [reader.md](reader.md) — то же для читалки `Reader`: интерфейс на
  `wxl.winui`, своя страница, листание, полка, панель, хранение.
- [fb3_model.md](fb3_model.md) — устройство модели книги: слои, контейнер,
  дерево узлов, позиции чтения.
